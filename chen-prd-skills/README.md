# chen-prd-skills

> Standardized PRD writing specification — 10-chapter structure, requirement IDs, 4 priority levels, and a pre-submission checklist.

## Core Capabilities

| Capability | Description |
|------------|-------------|
| 10-chapter structure | Problem Statement → Goals → Non-Goals → User Stories → Requirements → Success Metrics → Open Questions → Timeline → Dependencies & Risks → Appendix |
| Requirement IDs | US-XX (User Story) / FR-XX (Functional) / NFR-XX (Non-Functional) / G-XX (General) / Q-XX (Question) |
| 4 priority levels | P0 (must deliver) → P1 (this iteration) → P2 (resource-dependent) → P3 (future) |
| 10-item checklist | Pre-submission self-review covering completeness, testability, and risk |
| 3 reference docs | Spec guide + writing guide + blank template |

## Triggers

`PRD`, `product requirements`, `requirements doc`, `write requirements`, `user story`, `functional requirements`

git clone https://github.com/cyj4578/chen-skillshub.git
