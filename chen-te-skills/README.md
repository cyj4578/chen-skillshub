# chen-te-skills

> PRD test review skill — 5 review dimensions, 33 systematic checks, 4 severity levels, and structured audit reports.

## Core Capabilities

| Capability | Description |
|------------|-------------|
| 5 review dimensions | Structural completeness / Logical consistency / Requirement completeness / Testability / Risk completeness |
| 33 systematic checks | Covers all gap categories with thorough coverage |
| 4 severity levels | P0 Critical / P1 Major / P2 Minor / P3 Info |
| Structured report | Overview → Issue list → Fix suggestions → Improvement priorities |
| 3 reference docs | Review checklist + common gap types + report template |

## Pipeline

Designed to pair with [chen-prd-skills](../chen-prd-skills/):

```
chen-prd-skills (Write) → chen-te-skills (Review) → Fix & Re-review
```

## Triggers

`review PRD`, `PRD audit`, `gap detection`, `test PRD`, `requirements review`, `PRD quality check`

```bash
git clone https://github.com/cyj4578/chen-skillshub.git
```
