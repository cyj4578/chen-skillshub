# 陈氏知识网 (chen-knowledge-web)

> 知识组网扩展技能——将任意知识点展开为横向扩展 + 纵向深挖 + 背景 + 典故 + 影响的网状结构

## 核心功能

- **5维展开**：横向扩展 × 纵向深挖 × 背景来源 × 典故出处 × 产生影响
- **同名多义处理**：罗老师 → 罗永浩 / 罗翔 / 罗永康逐一展开
- **同一时间线**：历史事件自动补充同期全球大事件（金融/技术/政治）
- **副作用补充**：产品/技术类自动补充反作用/风险
- **产业链关联**：工业/农业类补充上下游

## 触发词

```
组网、扩散、知识点扩展、知识网络、知识图谱
展开讲讲、详细说说、深挖、横向对比
同一时间线、同名、多义、查一下这个人
```

## 使用示例

```
你: 万有引力
输出: 横向(重力/磁力) + 纵向(牛顿力学→相对论→量子重力) + 背景(1666) + 典故(苹果落地) + 同期大事件

你: 1919年
输出: 中国五四运动 + 越南胡志明 + 美国种族骚乱 + 日本大正民主 + 凡尔赛条约 + 西班牙流感

你: 尿素
输出: 氮肥/磷肥/钾肥对比 + 副作用(土壤酸化) + 产业链(天然气→合成氨→尿素)

你: 张总
输出: 张一鸣 + 张小龙 + 张朝阳 + 张勇 + 张近东 逐一展开
```

## 模型说明

```
输入知识点 → 5维展开 → 每个子节点继续展开 → 网状输出
```

每个知识点从5个维度展开：

| 维度 | 方向 | 方法 |
|------|------|------|
| 横向扩展 | 同级关联 | 同类项、上级归纳、下级拆分 |
| 纵向深挖 | 层级深挖 | 结构/组成、底层机制、关联因素 |
| 背景来源 | 来龙去脉 | 起源、历史脉络、相关定义 |
| 典故出处 | 文化附着 | 历史故事、诗词成语、名人引用 |
| 产生影响 | 辐射效应 | 对后世、行业、日常生活的影响 |
