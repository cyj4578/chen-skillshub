## 快速开始

### 安装方式

**方式一：Git Clone（推荐）**
```bash
git clone https://github.com/cyj4578/chen-skillshub.git ~/.workbuddy/skills/chen-skillshub
```

**方式二：单个 Skill 下载**
访问对应目录，下载 `SKILL.md` 到本地 `~/.workbuddy/skills/<skill-name>/`

### 使用示例

```
# PRD 书写
触发词：PRD、产品需求、需求文档、写需求

# PRD 评审
触发词：审查PRD、评审PRD、检测漏洞、PRD质量检查

# Python 查询
触发词：Python语法、列表、字典、函数、类、装饰器

# 知识组网
触发词：组网、扩散、知识点扩展、展开讲讲、深挖、横向对比
```

## Skill 联动

### PRD 工作流

```
chen-prd-skills（书写）
    ↓
chen-te-skills（审查 33 项检查点）
    ↓
修复问题 → 提交评审
```

### 知识组网工作流

```
触发词 → 5维展开
    ├── 横向扩展（关联知识点）
    ├── 纵向深挖（底层机制）
    ├── 背景来源（历史脉络）
    ├── 典故出处（文化语境）
    └── 产生影响（后果与启示）
```

## Skill 详情

### chen-prd-skills

**产品需求文档书写规范**

- 10 章标准结构（问题陈述 → 目标 → 非目标 → 用户故事 → 需求详情 → 成功指标 → 开放问题 → 时间计划 → 依赖与风险 → 附录）
- 需求标识规范（US-XX / FR-XX / NFR-XX / G-XX / Q-XX）
- 4 级优先级定义（P0-P3）
- 10 项评审 Checklist

📁 包含参考文档：
- `references/PRD规范说明.md`
- `references/PRD书写指南.md`
- `references/PRD-模板.md`

### chen-knowledge-web

**知识组网扩展技能**

5 维核心模型：

| 维度 | 说明 |
|------|------|
| 横向扩展 | 关联知识点（如苹果 → 香蕉/葡萄）|
| 纵向深挖 | 底层机制（如苹果 → 苹果树 → 气候）|
| 背景来源 | 历史脉络与出处 |
| 典故出处 | 文化语境与典故 |
| 产生影响 | 后果、影响与启示 |

**扩展能力**：
- 同一时间线（历史事件 + 同期全球大事件）
- 同功效替代品对比
- 反作用 / 副作用 / 风险
- 产业链上下游关联
- 同名多义逐一展开
