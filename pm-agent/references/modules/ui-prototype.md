# UI 原型模块

## 模块定位

pm-agent 子模块。可独立调用，也可被编排引擎串联。将功能和架构转化为可视化的页面设计方案，偏好 **Ant Design 3** 设计风格。

## 独立调用

```
@skill:pm-agent 帮我设计UI原型，功能清单和架构如下：XX
```

或被引擎在 DAG Step 5 自动调用（传入功能清单 + 架构设计）。

## 设计风格基线

- **框架风格**：Ant Design 3（优先）
- **布局偏好**：结构化、信息层级清晰
- **色彩**：功能色明确（主色 #1890FF / 成功 #52C41A / 警告 #FAAD14 / 错误 #F5222D）
- **交互**：操作路径短、反馈即时、容错设计
- **多端适配**：优先移动端（小程序/App），管理后台 PC 端

## 输入要求

| 参数 | 必填 | 说明 |
|------|------|------|
| 功能清单 | 是 | 来自功能清单模块的输出 |
| 架构设计 | 是 | 来自系统架构模块的输出 |
| 端类型 | 否 | 小程序/App/Web 管理后台/多端，默认小程序+管理后台 |

## 输出结构（4 模块）

### 模块 1：页面清单

按端分组，列出所有页面：

| 编号 | 页面名称 | 端 | 所属模块 | 说明 |
|------|----------|-----|----------|------|
| P01 | 首页 | 小程序 | 用户端 | ... |

### 模块 2：页面结构描述

每个页面包含：
- **页面路径**（路由）
- **布局结构**（顶栏/底栏/内容区的组件排布）
- **组件清单**（按钮/表单/列表/弹窗等，标注类型和关键属性）
- **数据来源**（哪个 API / 哪个数据表）
- **交互状态**（加载中/空数据/错误/成功/权限不足等）

### 模块 3：交互规范

- 导航方式（TabBar / 侧边栏 / 面包屑）
- 表单校验规则
- 操作反馈（Toast / Modal / 页面跳转）
- 手势交互（如下拉刷新、滑动操作）
- 权限控制（角色/状态切换的行为差异）

### 模块 4：多端差异（如适用）

| 差异点 | 小程序端 | 管理后台 | 说明 |
|--------|----------|----------|------|
| ... | ... | ... | ... |

## 执行步骤

```
1. 根据功能清单枚举所有页面
2. 按端分组，建立页面清单
3. 逐个页面描述布局结构和组件
4. 定义交互规范
5. 标注多端差异
```

## 实战经验

- 直播系统：8 页面（小程序 5 + 管理后台 3），视频号 SDK 嵌入，直播预约入口设计
- 签到功能：7 页面（小程序 4 + 后台 3），签到日历组件，抽奖弹窗交互
- 账号注销：7 页面（小程序 6 + 状态页 1），三端差异对比，冷静期撤销提示
- 山姆代购：9 页面（用户端 5 + 商家端 4），双角色 TabBar 切换设计，wx.reLaunch 切换交互
